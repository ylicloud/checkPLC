## 2026-08-14（当前）

**重写 README：新笔记本可按文档安装、运行并独立通检**

- 根目录 `README.md` 按现场用户重排：先安装启动，再写界面操作，工程机导出放到后面
- **新笔记本**：只需 Windows 10/11 + Python 3.10+（勾选 PATH）+ Chrome/Edge；双击 `setup.bat`（仅首次）→ `run.bat` → http://127.0.0.1:8000
- 补充 Mock 首次验证（连接 → 加载 `example_cabinet` → DI/AI 模拟按钮）、停止服务、常见安装失败处理
- **界面操作**：按 连接 / 配置 / DI / AI / DQ / AQ 逐页写清填什么、点什么、真机怎么测
- **真机**：同网段、TCP 102、PUT/GET、DB 非优化；通检结束后换回用户正式程序
- **Portal 导出地址**：推荐先打开工程，`export.bat` 附加正在运行的 TIA（不必给工程文件夹）；支持 **V20 / V21**，`--project` 指向 `.ap20`/`.ap21` 文件为备选
- README / 连接页写明：真机必须勾选 **允许来自远程对象的 PUT/GET 通信** 并重新下载，否则报 `0x81/0x04`
- 通检 DB 默认改为 **DB810 / DB811**，降低与对方工程 DB10/DB11 冲突；Web 连接页与柜配置同步
- **删除 `workspace/Main.xml`**：对方已有主程序时不要覆盖 OB1；导入 `FC_IO_Apply.scl` 后，在现有 Main 里调用该 FC
- **配置页按钮**：从已打开的 TIA Portal 一键导出模块地址并加载柜配置，不必再运行 `export.bat` + `aml_to_cabinet.py`
- 导出后同类模块名称加序号（如 `1.DI16`、`2.DI16`），避免十个相同 DI 无法区分
- 导出**不需要**管理员运行 Web；需加入 **Siemens TIA Openness** 组，并与 Portal 同一 Windows 账户

## 2026-07-23

- DI / AI 大字区：通道号 + **模块名称（x/y）**；Mock 按钮紧挨大字区；通道表可折叠并区内滚动

- 配置列表可见多文件；毫安整段词片；AQ 4～11 循环；表增加模块名称列

## 2026-07-23 · `9a3b9ff`

**加快语音播报并优化 AI 通检逻辑**

- 连接页可调语音速度；支持打断旧播报（不排队）

- 配置项：`ai_announce_threshold_pct`、`ai_announce_cooldown_ms`
- 词片生成脚本扩展（`scripts/generate_wavs.py`）
